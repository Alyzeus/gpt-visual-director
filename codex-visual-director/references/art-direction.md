# 导演、参考拆解与画面任务

## 参考先拆关系

为每张实际看过的图记录：

| 字段 | 内容 |
|---|---|
| reference / role | 真实文件或来源；材质、构图、配色、身份或文字参考 |
| observed | 能在图中定位的对象、层级、受力、色块、反射、图文关系 |
| inferred | 对表现机制的解释；与可观察事实分开 |
| transferable | 可用于本任务的抽象关系 |
| avoid | 现成标识、无关元素及不应照搬的具体表达 |
| uncertainty | 看不清或来源未确认的细节 |

不自动建立图库，不把用户先前试做的素材库设为依赖。当前任务需要的参考足够即可；经验检索可无命中。

## 选参与冻结

只在方向存在实质歧义时用 2–3 张已实际查看的参考对齐审美，差异至少涉及配色、空间组织、阅读路径中的两项。每张注明来源、借鉴项与不借鉴项；文字方案不冒充视觉候选。新生成的缩略图须已有出图授权并计入预算。

沿用此前或任务开头已经确定的方向时记 inherited；本轮从候选中实际挑选时才记 user_selected；授权导演代选时记 delegated 并继续。只有用户要求等选择才将它设为停点。无需用户每次点击“冻结”，也不把修订需求视为违规。

把“电影感、通透、克制”等术语落成能看见的特征，例如“室内外光源分工、环境结构可辨、人物动作受空间限制”。短术语表写进 Brief，后续匹配审查复用同一含义。记录 Brief 修订号；选择改变时保留旧理由并重新检查受影响项。

来源与用途分开：已知是生成图，即使由用户上传也标 generated，并说明用户提供。用户批准的生成图可约束连续性、作编辑底图；验证原作身份或外部风格时仍看独立来源。用户明确以生成图为风格目标时可以采用，但不能据此证明它忠实于外部原作。

## 方向卡

```yaml
direction: A
claim: 用极少的稳定结构表现雨后片刻的犹豫
first_glance: 人的回望与门框之间的空隙
reading_path: 面部、松开的手、门外反光
spatial_mechanism: 身体与视线方向错开，门框说明原本的去向
material_mechanism: 衣料随肩部扭转，头发主要服从重力
text_strategy: 无文字
preserve: [H01, H02]
risk: 手可能读成正在伸向拉手
production: 原生图像生成；局部编辑是否可控要看实际结果
```

另一方向应改变表达机制与构图/图文/材质中的至少一项，而非只改成冷色、加辉光或放大人物。用户已选路线时不强制再做竞选。

选择时说明作品为何更适合目标，并保留被否方向的一个具体理由。判断可有主观性；不要用虚构的客观分数包装审美。

## 将表演转成一张图能表达的关系

“眼睛先转、身体后动”是导演的时间设想。进入生图时改写为：身体朝门外、头部回转、瞳孔指向画外对象、肩膀扭转有限。不能声称单帧已经证明动作时间顺序。

对于“刚松开”的手，检查手指与把手的距离、方向、遮挡和身体动作是否互相解释；不靠故事说明强行判定动作成立。局部放大保留相邻把手与手腕，避免只看手指而失去上下文。

## 材料与图形

薄边、拉紧面、下垂、褶皱、反光方向和纹理尺度应支持同一种材料。厚壳形体加细纹不一定变成轻薄布料。印在载体上的图形应随曲率与遮挡变化；悬浮装饰不能自动替代图形与载体的关系。

## 制作任务卡

先确定第一视觉优先级，并以少量可见关系形成检查点。需要时记录可让步项及取舍，但不降低用户硬条件。比如大透视要检查近手→头肩→躯干→足部的尺度链；俯视要有水平地坪或向下收缩空间等证据。示例不是所有作品必须套用的构图。

分析可以深入，制作指令保持精简：主体、核心空间/构图关系、关键身份、必要光材与交付条件。准确文案和保留项不能因压缩而丢失；不把方向讨论、备选方案与全部风险说明一起塞进提示。增加支撑、细节或装饰后，要检查是否削弱第一眼表达。

制作策略随任务选择：原生图像负责绘画性视觉；确定性代码负责需要准确的几何与文字。两者可以配合，但不能为了展示工具而增加路线或自动重做已批准部分。

导演应在 D1 收束为可以执行的任务。对未知的工具效果保留验证条件，不在 D1 把所有动作和细节讨论到机械化。

制作前用 `assets/production-card.md` 自检输入、约束、工具、字体与预算。记录通过依据后直接执行已授权动作；缺图、缺字、未知准确文案等实际阻碍需先解决。普通偏好可说明默认选择，不制造额外审批。
