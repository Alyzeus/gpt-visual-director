# 字形与标题设计

先确定准确文案、阅读距离、风格角色及哪些字允许变形。正文与公式以识读为先；短标题可以探索笔画切角、连笔、负空间或材质，但保留识别骨架。

1. 实际看批准参考，拆开字形、字距、排列和材质；不把某个字体名称当完整设计方法。
2. 先看普通字形的字重、可见字高与字内空间，再增加变形。既要看全尺寸，也要按预期缩小显示检查易混字和断笔。
3. 原生图像工具可探索绘画性字形；成图仍需逐字核对。准确文案受影响时，使用实际可用字体进行确定性排版，或提出需要专门制作的部分。
4. `render_layout.py` 提供现有字体的横排、换行、对齐与墨迹检查，不设计新字体、不提供任意描边/扭曲/竖排功能。未知字段会拒绝，不能写进 JSON 就称已实现。
5. 字形清楚不等于版式成立：回到主视觉、阅读顺序和气质检查。需要可编辑源文件时，实际重开、改字并重渲；跨软件字体兼容仍需验证。

检索 `VD-T004 / VD-T005 / VD-T007` 可得到相关方法及反例；种子卡是待验证假设，不等于已验证字形库。
