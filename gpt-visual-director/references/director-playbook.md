# Director Playbook · 创意与 Image 制作规范

## 1. 把抽象愿望翻译为可见关系

避免仅写“高级、科幻、史诗、赛博、电影感”。改为：

- **焦点**：哪一物体是主角，其他元素为什么辅助它？
- **构图**：视觉重心、负空间、层次、前后遮挡、观众视线从哪里开始？
- **用光**：主光方向、材质反射、暗区保留、主体与背景分离。
- **色彩**：主体色、环境色、强调色的比例及对比关系。
- **形态**：几何/有机、有序/凌乱、坚硬/柔软、密集/空白。
- **图文**：标题是视觉主体还是说明层？是否真能阅读？
- **反模板化**：指出必须避免的具体俗套，如没有目的的粒子、无故堆积的辉光、空泛未来都市。

当用户给参考图，描述能够看见的关系，不复制参考图具体文案、商标、人物身份；使用用户拥有使用权的素材，未知许可证标记待确认。

## 2. 两个真正不同的方案（只在需要时）

一个简短的创意卡：

```yaml
idea_id: A
one_line: 用「秩序从噪声中显形」表达数学结构之美
first_glance: 悬浮的对称结构
composition: 中央主体 + 两侧黑场留白
visual_grammar: 冷静的有限色域、可读结构、高对比轮廓
text_strategy: 下方独立标题区，文字尽量简短
image_role: 负责材质、环境、可视化主体
must_preserve: [对称关系, 标题原文]
risks: [过于科普化, 生图几何可能不准确]
```

另一方案不能只是改色；例如将“中央单焦点”变为“大型横跨刊头 + 偏置主体 + 图文冲突”，改变视觉叙事与观看路径。

## 3. 给 Image 工具的指令结构

采用紧凑、可测的自然语言，不必输出给用户大段元提示词：

- 输出：画幅与用途，如竖版艺术海报 2:3。
- 主体：具体外观、动作、材料，哪些视觉特征不可改变。
- 空间：主体位置、尺度、前后层次、留白比例。
- 艺术语言：构图对比、光线、色域、肌理，不是风格标签堆叠。
- 文字策略：逐字文案 / 尽量不给文字 / 文本预留区域。
- 不要：导致上一版失败的 1–3 个明确问题。

只有图像工具支持参考图的情况下才传入；不要拿文本描述冒充已上传。对于编辑，必须点名不变要素和目标区域。

## 4. 审美与成本

根据任务复杂度选 Fast/Standard/Deep；不要默认多图海选是质量必要条件。用户没有给张数限制时以单张基线开始，必要时做定向编辑；不要默认为了“对比”而制造额外调用。

## 5. 静态视觉与动态视觉的边界

来自四次《群论之美》探索：静态美术精细 ≠ 动画成熟，摄像机推拉 ≠ 对象或世界的连续变化。此 Skill 面向静态图像；当用户提出视频，应明确时间运动、主体动作、分镜与模型可用性需要另行设计。不能把静态运镜失败包装成视频成功。
