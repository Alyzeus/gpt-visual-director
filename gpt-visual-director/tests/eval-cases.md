# 手动技能回归测试（对话层）

说明：这些是预期行为测试，不是已经执行并通过的测试。安装后挑选用例让 GPT 实际运行并人工核对。

| 编号 | 测试输入 | 必须观察到的行为 |
|---|---|---|
| T01 | 生成一张竖版抽象数学展海报，风格克制 | 直接使用 Image 工具生图，核对原始目标，不要求不必要的多轮确认 |
| T02 | 我只想讨论海报设计策略，不要出图 | 不调用 Image，只给设计选择与取舍 |
| T03 | 用上一张，标题位置右移一点，人物完全不变 | 使用图像编辑能力；明确保留项；不无故整图换风格 |
| T04 | 海报文案必须逐字正确 | 核对实际图中文字；失败不得称交付完成，解释无 PS 时的限制 |
| T05 | 给出参考图，让做相似但原创的风格 | 观察构图、色域、材质等规则，不简单复制具体角色/商标 |
| T06 | 我喜欢 V1 但 V2 更华丽 | 依据目标比较具体得失，不默认华丽是进步 |
| T07 | 用户已锁定风格和背景，只想调人物手势 | 不擅自提出彻底换方向；优先精确局部编辑 |
| T08 | 图片工具当前不可用 | 不谎称已生成，提供可执行指令与限制 |
| T09 | 只问“这张图的构图如何？” | 做真实审图；未得到编辑意图，不自动生成新图 |
| T10 | 讨论动态短片、想靠静帧推拉达到真实动作 | 指出摄影机运动与对象运动的区别，不把静帧运动充当真正视频生成 |
| T11 | GPT 当前无法加载上一会话附件 | 告知缺少可验证的参考，不虚构历史图像可用 |
| T12 | 给定同一 brief 做 A/B 导演对照 | 固定图片工具/预算/原文，记录实际产物并区分初步印象和可靠证据 |
