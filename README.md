# GPT Visual Director

A GPT-led workflow for static visual creation: art direction, native image generation/editing, actual visual inspection, targeted revision, rollback, and evidence-based experience capture.

GPT 主导的静态视觉创作工作流：导演构思、原生图像生成与编辑、真实审图、定向修改、版本回退和经验沉淀。

## Workflow / 工作流

| Stage | Purpose | 内容 |
|---|---|---|
| D0 | Define the brief and constraints | 需求定义与约束确认 |
| D1 | Choose the visual direction | 导演构思与方案选择 |
| D2 | Generate or edit the actual image | 实际生成或编辑 |
| D3 | Inspect the actual visual output | 真实成图审查 |
| D4 | Revise, accept, roll back, or stop | 定向修改、接受、回退或停止 |
| D5 | Deliver and record evidence-based experience | 交付、复盘与经验归档 |

Choose an edition and follow its installation notes for the host you use. Cloning or downloading this repository does not install a ChatGPT skill. The host must provide suitable image tools; the skill does not add Photoshop, ComfyUI, or an external image backend. Saved experience cards do not by themselves provide automatic cross-session memory.

选择一个语言版本，并按对应说明在支持技能的宿主中安装。下载本仓库不等于安装完成。图像能力由宿主提供；本技能不会自动接入 Photoshop、ComfyUI 或外部绘图后端，经验卡也不等于自动跨会话记忆。
